## The entry

The deliverable is one word for the human who signs off on the work:

> **Weathervane**

The habit it catches: the sign-off faces whoever spoke to them last. Same
verdict, different wind. Nothing ships alongside the word — no caption, no
explanation, no punctuation — because the word has to land by itself.

## Run it

```sh
python3 main.py
python3 -c "print(repr(open('/output/entry.txt','rb').read()))"
# b'Weathervane'  — 11 code points, no trailing newline
```

Python 3.13, standard library only, deterministic, no network, no randomness.
